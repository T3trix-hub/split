# Скинулись — Telegram-бот со сплитом расходов

Мини-апп для компании друзей: заводите группу (поездка, квартира, вечеринка),
добавляете траты — бот сам считает, кто кому и сколько должен, и минимизирует
число переводов (алгоритм упрощения долгов, а не "каждый каждому").

## Что внутри

```
split-bot/
├── bot/
│   └── bot.py            # aiogram-бот: /start, кнопка WebApp, меню
├── backend/
│   ├── main.py            # FastAPI: группы, расходы, расчёт долгов
│   ├── models.py           # SQLModel-схемы (SQLite из коробки)
│   └── auth.py             # проверка подписи Telegram initData
├── requirements.txt
└── README.md
```

Готовый **прототип интерфейса** — файл `split-app.html`, который прислан отдельно
(и уже открылся у тебя как превью). Внутри Telegram он будет работать так же,
только за хранение данных отвечает не браузерное хранилище, а `backend/main.py`.

## Как это работает

1. Пользователь пишет боту `/start` → получает кнопку **"Открыть Скинулись"**.
2. Кнопка открывает мини-апп (`WebAppInfo(url=...)`) — обычная веб-страница,
   но с доступом к `Telegram.WebApp` JS SDK (тема оформления, данные пользователя, хаптик).
3. Мини-апп при каждом действии дергает бэкенд, передавая `Telegram.WebApp.initData`
   в заголовке — бэкенд проверяет подпись (`backend/auth.py`), чтобы никто не мог
   подделать запрос от чужого имени.
4. Бэкенд хранит группы/участников/расходы в SQLite и по запросу отдаёт
   готовый расчёт: баланс каждого участника + минимальный набор переводов
   для закрытия всех долгов (жадный алгоритм: самый крупный должник платит
   самому крупному кредитору, пока балансы не обнулятся).

## Запуск локально

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN=токен_от_BotFather
export WEBAPP_URL=https://твой-домен/app/   # см. ниже про деплой фронта

# бэкенд
uvicorn backend.main:app --reload --port 8000

# бот (в отдельном терминале)
python bot/bot.py
```

## Деплой

Telegram требует, чтобы мини-апп открывался по **https**, поэтому нужен реальный домен:

- **Фронт** (`split-app.html`, переименовать в `index.html`) — можно захостить
  бесплатно на GitHub Pages, Vercel или Netlify.
- **Бэкенд** (`backend/`) — любой VPS с Nginx + systemd, либо Railway/Render.
- В [@BotFather](https://t.me/BotFather) → `/mybots` → **Bot Settings → Menu Button**
  указать тот же URL, что и в `WEBAPP_URL`.

## Что можно докрутить для портфолио

- **Реальные Telegram-контакты** вместо ручного ввода имён — брать участников
  через `Telegram.WebApp.requestContact()` или добавление по инвайт-ссылке в группу.
- **Telegram Payments** — кнопка "Перевести" рядом с каждым долгом, открывающая
  оплату прямо в чате.
- **Категории трат + графики** — простая диаграмма расходов по категориям (Chart.js),
  показывает, что ты умеешь работать с визуализацией данных.
- **Push-напоминания** — бот раз в неделю присылает в группу, кто кому должен,
  если баланс не закрыт (по аналогии с твоим ботом для парикмахерской).
